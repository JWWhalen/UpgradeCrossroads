UPGRADE CROSSROADS 0.5.1
- Gear has a faction filter with exactly Alliance, Horde and Both.
- Defaults to the character's faction and saves the selection per character.
- Filters faction-tagged acquisition sources; shared/untagged sources remain.
- Source cycling follows the same selection. Switching filters preserves hunts,
  notes and active tracking. Current class, level and other filters still apply.
- Opposite-faction previews are clearly labeled. Their racial quests/history
  are not checked against the logged-in character; own-faction checks remain.
- 69 automated test groups and the existing offline layout checks pass.

0.5.0
- Main shell embeds Gear, Hunts, Settings, Help and Add item as exclusive pages.
  Only the in-game tracker remains a separate window; page geometry is shared.
- Removed custom native-button backdrops and duplicate labels. Action buttons
  fit actual text metrics; equipment and item lists use understated rows.
- Replaced tiny text chrome with native close and resize-grip art. Scale is
  available through the corner and a Settings slider.
- Solid controlled backgrounds, quieter colors and plain non-outlined body text
  replace the nearly transparent/outlined default shown in the user's screenshots.
- Circular minimap/header emblem with genuine RGBA transparency outside its rim.
- Migration preserves hunts, notes, sources, colors and deliberate low opacity.
- 64 automated groups, 12 offline layouts and RGBA texture checks pass. Actual
  client template/font verification is still required; no live playtest claimed.

0.4.0

  window header emblem. Bundled 64/256px TGA assets and source PNG included.

- Data snapshot remains 2026-10-13. No live playtest or data refresh claimed.

0.3.1
- Drag the bottom-right // corner to scale the whole window, including text,
  buttons and content. Works on planner, tracker, hunts, help and editor.
- Keep Shift held when starting the drag to resize/reflow the layout instead.
- Corner scaling keeps the opposite corner fixed and accounts for UI scale.
  Scale is bounded from 50% to 150% and saved separately for each window.
- Releasing the mouse, hiding a window or resetting it ends an active gesture.
- Updated tooltips, footer and guides. Expanded to 52 automated test groups.

0.3.0
- Redesigned native UI with sans-serif type, calmer panels, colored path
  accents, clear item hierarchy and purpose snippets throughout the addon.
- Item/source/zone search within the selected slot; inline source switching,
  item paging and direct tracking remain on the item cards.
- Chat buttons on cards, equipped gear, saved hunts and the tracker. Shift-
  click and right-click also insert links into unsent chat drafts. Cached
  links use the client item API; pending links ask for a retry after loading.
- All five windows support native layout resizing, independent scale controls,
  dragging and saved geometry. Compact tracker details scroll. Help and hunts
  remain scrollable; /uc resetwindows restores defaults without losing hunts.
- The tracker X dismisses it until /uc guide or another Track action.
- Saved hunts can hide obtained items; editing notes survives layout changes.
- Removed the character-screen Crossroads button and its loader hook.
- Preserved the separate close-button hit region on every window.
- Expanded to 49 Lua 5.1 test groups and seven offline layout fixtures, including
  each window at minimum size. No live client playtest is claimed.
- Catalog remains the 2026-10-13 snapshot; no gear/source refresh in this release.
