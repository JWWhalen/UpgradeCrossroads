UPGRADE CROSSROADS 0.7.0 - START HERE

INSTALL
1. Close WoW completely. Extract UpgradeCrossroads-v0.7.0-forever.zip.
2. Copy its UpgradeCrossroads folder into your working Interface/AddOns folder,
   replacing the previous files. Keep your WTF folder and saved hunts.
3. Check: Interface/AddOns/UpgradeCrossroads/UpgradeCrossroads.toc. Core, Data,
   UI and Media must sit directly beside that TOC, without another folder level.
4. Restart the game, enable the addon and type /uc. /uc status reports v0.7.0.
5. Run /uc resetwindows once if you want the new default size and position.

ONE MAIN WINDOW
Journal, Hunts, Settings, Help and Add item share one window. Switching
pages hides the previous page, so settings cannot sit behind the gear list.
The pages share position, size, scale and one native close button. The small
in-game tracker stays separate and hides while the main window is open.

The circular minimap emblem has transparent corners, with no square background.
Left-click opens/closes the main window, right-click opens Hunts, and dragging
moves the shortcut around the minimap. The emblem also appears in the header.

CLEANER CONTROLS
- Equipment and item choices use understated list rows instead of gold buttons.
- WoW's standard font is the default throughout the addon, without heavy
  outlines. Plain readable text, text size and outlines remain options in Settings.
- Native action buttons use their own font string and text measurements. Custom
  button backdrops and duplicate labels are removed.
- The main background is a solid, controlled color instead of depending on an
  old dialog texture. Default opacity is 100%; reduce it in Settings if desired.
- The tiny A-/A+ and text-based close/resize controls are gone. X uses the native
  close template, and the lower-right corner uses a resize-grip texture.
- Journal, Hunts, Help and Add item share the darker panorama, aged parchment
  and native frame style. Settings keeps its simpler controls without scenery.

FACTION FILTER
In Journal, open Filters and cycle Alliance, Horde and Both. The first selection
uses your character's faction, and your choice saves per character. Shared or
untagged sources stay visible. Class, level, solo/crafting/AH and search filters
still apply. Changing the view does not remove hunts or change their sources.

Opposite-faction quests can be inspected for another character, with a clear
unavailable-to-this-character label. Their racial quests/history are not tested
against the logged-in character; its class/gear rules remain. Current-faction
race and completed-quest checks are retained. Sources are tagged from the dated
catalog; missing faction data is not guessed from place or NPC names.

CLASS AND SPEC
Your class is detected automatically. In Journal, click the spec button to cycle
only that class's choices. These are manual choices, not talent auto-detection.
There are 29 choices across nine classes, including Survival melee/ranged and
Feral cat/bear. Specs sharing a role share starter weights, not independently
simulated rankings. /uc weights customizes only the selected spec; reset restores
only its defaults. Existing broad-role choices and custom weights are migrated
without deleting hunts, notes or saved settings.

Hunters no longer receive thrown weapons as ranged-slot recommendations. Melee
weapon DPS does not count toward ranged Hunter stat sticks. Feral cat/bear do
include main-hand DPS, reflecting Forever's form weapon-DPS rule.

USING IT
The Journal opens first. Select any ranked item under an equipment heading to
read its parchment description, source and reward. Track, Show on map, Remove
and Chat stay with that item. Click its reward for immediate tracking. Source
cycles alternate eligible sources. Search covers items and sources in the
selected equipment filter.
Active lists suggestions, Completed records observed ownership, and Removed
retains hidden suggestions for restoration without deleting their saved notes.
Click a slot heading to collapse it; the bottom control sets picks per slot.
Choose All there to browse every matching result without a ten-item cap.
Use Equipment to select one slot or return to all equipment. The detail pane
includes the equipped item's name, stats and score beside the candidate's model
comparison, with Chat for the equipped item. Filters retain the acquisition
paths. There is no separate Compare tab.

Chat, Shift-click or right-click inserts an unsent item link into a chat draft.
You choose the channel and send it. Ctrl-click previews gear. If a link is not
cached, wait and click Chat again. Hunts retains notes and checklist progress.
Add item and Set location use an embedded editor, with a Cancel button to return.

SETTINGS AND SCALE
Settings has four presets, background opacity, custom background/accent/border
colors, a native color picker or HEX, font/text size, outlines and a scale slider.
The native color picker is a system dialog; the settings page remains in place.

Drag a title to move its window. Drag the lower-right grip to scale. Hold Shift
when starting the drag to resize the layout instead. Main pages all share that
geometry; the tracker has its own. Compact content scrolls instead of overlapping.
Readable mode keeps text at least 12 screen pixels (14 at Largest), with an
80-150% window scale range. Turning it off allows 50-150%; tiny text stays tiny.

Existing hunts, notes, weights, custom sources, map corrections and custom colors
are retained. Older font settings switch once to the WoW default; reselect Plain
in Settings if preferred. Subsequent explicit font choices survive reloads. The
earlier migration makes an old default 95% background fully opaque; a deliberately
lower opacity is kept.
Restore appearance resets look preferences only. /uc resetwindows resets geometry.

FIRST LIVE CHECK
1. Confirm your detected class and cycle its spec choices. Verify only your
   class appears; try different roles if your class supports them.
2. Switch all five pages. Only one should appear, with no gear visible behind it.
   Journal, Hunts, Help and Add item should share the illustrated style; Settings
   should keep its plain controls.
3. Try the main window and tracker at your normal UI scale and Largest text.
4. Try Equipment/all slots, the equipped comparison and its Chat action, source
   selection, Track/map, hunt notes and editor Cancel. On a
   Hunter, confirm thrown weapons are absent from ranged recommendations.
5. Change settings, close/reopen the window and /reload. Check everything saves.

Automated Lua checks, circular RGBA assets and offline layouts are included.
The attached screenshots exposed issues the old offline skin could not predict;
actual client font/template rendering still needs an in-game pass for this build.
PREVIEW.png and GUIDE_PREVIEW.png are labeled offline illustrations, not live QA.
Catalog remains the 2026-10-13 snapshot. This revision consolidates gear browsing
and shares the journal theme across the content pages.

The full source archive includes tests, tools, logo masters and the maintenance
guide. Runtime needs no Python. Do not copy development files into AddOns.
